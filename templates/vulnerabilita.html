ACCESSI

Controllo degli accessi

Dati di altri utenti raggiungibili cambiando un numero nell'indirizzo (IDOR), privilegi da amministratore ottenuti senza averli, login aggirabile.

Impatto: furto di dati, violazione GDPR

INIEZIONI

Iniezioni

SQL e NoSQL, comandi di sistema, template lato server (SSTI): input che il sito esegue invece di trattare come semplice testo.

Impatto: lettura o modifica del database

SERVER

Lato server

SSRF, XXE, deserializzazione insicura ed esecuzione di codice remoto: le falle che aprono le porte dell'infrastruttura.

Impatto: controllo del server

CLIENT

Lato browser

XSS memorizzato, riflesso e DOM, CSRF, prototype pollution: attacchi che colpiscono i tuoi clienti attraverso il tuo sito.

Impatto: account dei clienti compromessi

LOGICA

Logica di business

Prezzi modificabili nel carrello, coupon riutilizzabili, passaggi obbligatori saltati, race condition sui pagamenti.

Impatto: perdite economiche dirette

SESSIONI

Autenticazione e sessioni

Token JWT manipolabili, sessioni che non scadono dopo il logout, protezioni deboli contro i tentativi ripetuti di accesso.

Impatto: accesso agli account altrui

API

API

Endpoint senza autenticazione, campi che l'utente non dovrebbe poter modificare (mass assignment), limiti di frequenza aggirabili.

Impatto: dati e funzioni esposte alle app

CONFIG

Configurazioni e cloud

Servizi esposti per errore, pannelli di amministrazione raggiungibili, header di sicurezza mancanti, componenti con vulnerabilità note.

Impatto: porta d'ingresso per altri attacchi
