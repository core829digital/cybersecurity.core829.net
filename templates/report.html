CRITICA · CVSS 9.1VULN-003

Il prezzo del carrello si può modificare dal browser

Il server accetta il prezzo inviato dal browser invece di ricalcolarlo. Chiunque può acquistare qualsiasi prodotto a 0,01 €.

Prova di sfruttamento

POST /api/carrello/conferma
{ "prodotto": 4471, "quantita": 1, "prezzo": 0.01 }

→ 200 OK · ordine #10582 creato a 0,01 €

Correzione

Ricalcolare sempre prezzo e totale sul server partendo dal catalogo, ignorando i valori inviati dal client.
